# Mobile 3D experience

At widths up to 700 CSS pixels, the home introduces João Victor and the contact actions before an optional 3D demonstration. The existing renderer opens the toolkit tower fully assembled. Four selectors change the model; the labeled replay button reuses the existing 4.2-second construction animation. Reduced motion keeps the finished model and disables replay.

The scene is 220–300 CSS pixels high. Its controls follow it in the document flow. The complete shared reading content remains below, with the repeated reading hero hidden only when JavaScript has loaded the 3D successfully. No JavaScript or a graphics failure retains the reading hero and recovery path. Hidden viewer cards retain their desktop behavior and content but are not the mobile reading surface.

Mobile initialization and selection do not scroll the page to the top, reserve a scroll track or drive card text with page scrolling. Vertical touch gestures and browser pinch zoom remain native. Rotation begins only after a horizontal gesture exceeds the movement threshold; vertical or equally diagonal gestures do not capture the pointer or interrupt replay. Mouse dragging and keyboard left/right rotation remain available. Keyboard up/down keeps native page scrolling on mobile.

Resizing into mobile completes any unfinished guided tour without a scroll command. Resizing out preserves completion and the selected model rather than starting the tour again. The existing completed tablet layout at 701–1100 pixels and the desktop guided tour are retained. The canvas intersection observer still stops rendering when the scene is offscreen; replay resumes only while the scene is visible.

The footer brand links to the visible home `#main` anchor in every mode. Mobile 3D also resolves the legacy `intro` navigation command to `main`; direct reading keeps its original intro target. Startup honors explicit fragments but does not issue an implicit mobile intro scroll after loading the renderer. Replay uses the same localized text for its visible label, accessible name and tooltip.

Local verification covers touch direction separation, source importability, story progression, replay motion, startup fragment behavior, localized replay text, logical introduction/action/canvas order and preserved shared content. Native browser checks of layout, gestures, selection, replay, rotation, reduced motion and breakpoint changes are required before publication; this document alone does not establish device QA or deployment.

No dependency, network provider, collected data or storage was added. The same static assets and renderer are reused. Hosting and traffic costs remain the existing scenario; actual usage and charges are not inferred from local tests.
